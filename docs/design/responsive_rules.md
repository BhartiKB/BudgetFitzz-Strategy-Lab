# Responsive rules

## 1440 and 1280 px

- Fixed 236 px rail; content max width 1320 px.
- Twelve-column content grid with 24 px gaps.
- Evidence hero uses a 7/5 split; planner media remains visually dominant.

## 768 px

- Rail collapses to a compact top bar and bottom navigation.
- Main grids become two columns where the reading order remains clear.
- Calendar is horizontally scrollable; tables keep an explicit scroll region.

## 390 px

- Single-column route content with 16–20 px gutters.
- Minimum control size is 44 px; body copy never drops below 14 px.
- Signal and day strips scroll horizontally without causing page overflow.
- Plan and studio show one dominant media item per row.
- Filters and secondary navigation use sheets/menus.
- Persistent bottom navigation accounts for safe-area inset.

Reduced-motion preferences disable transitions and smooth scrolling. Focus indicators remain visible on every interactive element.
