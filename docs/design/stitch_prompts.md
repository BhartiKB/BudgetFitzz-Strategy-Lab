# Stitch design prompts

Private Stitch project: `BudgetFitzz Social Strategy Workspace` (`5443357960226073427`).

The prompts sent only BudgetFitzz UI labels, summarized metrics, strategy findings, and asset descriptions. Raw datasets, source files, API keys, and private media were excluded.

## Direction 1 — Editorial Social Studio

Screen: `87b22eca901e4c49b47f17ce46ee1656`

Create an editorial social-strategy studio with warm ivory paper surfaces, sage, forest, terracotta and pale-citrus accents. Pair Newsreader-style editorial headlines with neutral sans-serif UI text. Use a compact route rail, an evidence-led diagnosis hero, four observed signal cards, a seven-day plan, featured media, validation state, and a mobile inset. Avoid conventional dark SaaS dashboards.

## Direction 2 — Instagram Creator Workspace

Screen: `9f055cb8d9894272bcb22feba3e7f0ab`

Create a tactile Instagram creator workspace with a planner, visual card grid, filters, storyboard and caption editor, creator signals, and agent feedback. Show exactly five 4:5 posts and two 9:16 videos. Prioritize daily workflow density and preview-to-caption pairing.

## Direction 3 — Fashion Analytics Magazine

Create an asymmetric fashion-intelligence magazine using parchment, paper white, espresso, muted violet and warm peach. Present diagnosis, format and pillar analysis, evidence, before/revised strategy, the seven-day filmstrip, media, agents, validation and submission as an editorial broadsheet.
