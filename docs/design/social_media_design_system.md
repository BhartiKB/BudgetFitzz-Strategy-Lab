# BudgetFitzz social-media design system

## Tokens

- Canvas: warm ivory `#F7F3EA`
- Surface: paper `#FFFDF8`
- Text: charcoal `#1F2621`
- Primary: forest `#496657`
- Support: sage `#CBD8C7`
- Editorial accent: terracotta `#B65435`
- Active/highlight: pale citrus `#DDF58B`
- Error: brick `#A3382B`
- Border: charcoal at 12% opacity

Headlines use Newsreader or a readable editorial serif fallback. Navigation, body, labels and tabular data use Inter or the system sans-serif stack. Controls use 8 px radii; cards use 12–16 px. Default elevation is a fine border; only drawers, menus and active preview surfaces use a soft ambient shadow.

## Reusable components

- App rail and mobile bottom navigation
- Route header, status chip, value-kind label
- Evidence signal card and source note
- Plan strip, plan card and media preview
- Filter group and segmented control
- Caption/CTA panel and storyboard disclosure
- Metric table, chart figure and interpretation note
- Agent trace row and validation group
- Submission file card
- Loading skeleton, empty state and actionable error state
