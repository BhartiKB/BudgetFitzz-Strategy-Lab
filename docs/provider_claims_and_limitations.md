# Provider claims and limitations

The system supports an automated Veo API execution path when paid credentials are configured. In the current demonstration, Veo is used through its manual web interface. The BudgetFitzz workflow generates the prompt and generation package, while generated media is imported into the same validation, post-processing, approval and packaging pipeline.

No Veo API request has been made or claimed. No Google Flow website automation is performed. Hugging Face remains an available guarded fallback but is not reported as connected unless a verified request succeeds. The local fallback is available offline.
