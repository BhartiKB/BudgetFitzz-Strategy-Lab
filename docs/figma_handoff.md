## Pages and layout targets

The intended editable Figma page structure is: `00 — Cover`, `01 — Foundations`, `02 — Components`, `03 — Desktop Screens`, `04 — Responsive Screens`, `05 — User Flows`, `06 — Data Visualisation`, `07 — Asset Gallery`, `08 — Prototype`, `09 — Developer Handoff`, and `99 — References`.

Desktop frames map to Overview, Content Studio, Performance, Strategy, Workflow, and Validation. The responsive frame is a 390 px-wide mobile navigation/content layout. The app stays offline: images and video preview references are local repository assets.

## Data rules

The browser reads only `app/data/platform_manifest.json`; the manifest is generated by `build_app_data` during the pipeline. It contains observed facts, agent outputs, local asset references, and trace summaries. It does not contain a separate browser formula engine. `data/processed/metric_contract.json` remains machine-readable source material and is intentionally not displayed in the product UI.
