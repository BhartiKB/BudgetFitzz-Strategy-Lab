# Manual Google Flow / Veo workflow

1. Open Content Plan and select an asset.
2. Review the exact **Generation Prompt** and copy it or export the JSON package.
3. Select **Open Google Flow**; login and generation remain user-controlled.
4. Download the media manually.
5. In Studio, use **Import Generated Media** and select Google Flow / Veo, Manual web interface, Free website credits, INR 0 and the matching asset.
6. The system creates a validated candidate version. Review it, then approve through the human-approval workflow before it can replace the active asset.

The demonstration does not automate Google login, CAPTCHA, prompt submission or downloading. No claim is made that Veo API was used.
